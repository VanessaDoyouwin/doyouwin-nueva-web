# Doyouwin · Nueva web (contenido completo)

Página de la nueva web de Doyouwin en un único archivo: `index.html`.

## Cómo editar

1. Descarga o clona el repositorio.
2. Abre `index.html` en un editor de texto (VS Code, por ejemplo) y haz los cambios.
3. Para verlo, abre `index.html` en el navegador.
4. Sube los cambios con un commit (o edítalo directamente en GitHub con el botón del lápiz).
